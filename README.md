# Quintessent.one

This repository contains a minimal constitutional coherence map expressed as a binary tree.

## Files

- `constitution-tree.json` — structured binary-tree data
- `index.html` — simple static viewer for the tree

## Tree intent

The tree starts from **Coherence** and branches into paired constitutional ideas such as:

- Freedom / Responsibility
- Expression / Association
- Equality / Justice
- Privacy / Participation

Open `index.html` in a static web server or publish the repository with GitHub Pages to view the tree.
